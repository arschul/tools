How to run it

It's a conversation, not a quiz. Read the opening line as if you were just chatting — the wording already does the work, so never name the grammar. Use the follow-ups to keep the student talking until you've heard enough.

Then record one thing only: did the target form come out, and was it right? Keys 1–4 score, Enter moves on.

If a target never fits the conversation naturally, skip it — a skip is left out of the average rather than counted as a zero.
